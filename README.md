# My Rhythm

Personal planner/tracker prototype.

Current version is a simple static HTML app designed primarily for iPhone use.

## Run locally

Open `index.html` in a browser.

## Structure

The project is intentionally kept simple so it can later be extended with:
- statistics and graphs
- calendar and history
- backup/export
- reminders
- user accounts and authentication
- cloud storage

For the first online version, no backend or external service is required.
